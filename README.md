# SETCool Management
Starter full-stack web untuk laporan pekerjaan AC + kuitansi.

## Menjalankan
1. Install Node.js 20+.
2. `npm install`
3. `npm run dev`
4. Buka http://localhost:3000

Versi starter ini memakai penyimpanan browser agar bisa langsung dicoba.
Untuk versi online multi-device, hubungkan Supabase pada tahap berikutnya.
